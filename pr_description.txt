🎯 **What:** The vulnerability fixed
An open redirect vulnerability caused by directly assigning `window.location.href = window.location.href` to trigger a page reload.

⚠️ **Risk:** The potential impact if left unfixed
If an attacker can manipulate the URL prior to the reload action, directly re-assigning `window.location.href` to itself could redirect the user to a malicious external site. This is generally bad practice and can expose users to phishing attacks or unauthorized redirection.

🛡️ **Solution:** How the fix addresses the vulnerability
Replaced the assignment with `window.location.reload()`, which is semantically correct, explicitly reloads the current page without evaluating or re-assigning the URL string, and prevents any potential open redirect exploitation.
