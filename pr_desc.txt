🎯 **What:** The `toId` function in `src/modules/time/time.ts` used the insecure `Math.random()` function to generate the unique identifier's entropy component. This has been replaced with the cryptographically secure `globalThis.crypto.getRandomValues()`.

⚠️ **Risk:** `Math.random()` is not a cryptographically secure pseudorandom number generator (CSPRNG). The generated sequences can be predicted if enough entropy is observed, which could lead to ID collisions or allow an attacker to guess the IDs generated by the application. This is especially risky if these IDs are used in security-sensitive contexts like access tokens, database primary keys, or references where unpredictability is expected.

🛡️ **Solution:** The implementation now uses the Web Crypto API (`globalThis.crypto.getRandomValues`) with a `Uint32Array` to generate a secure random 32-bit integer. It then formats it as an 8-character hex string, appending it to the timestamp to match the existing ID format.
